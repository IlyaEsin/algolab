# K-й по величине элемент

Дан массив целых чисел и число `k`. Нужно найти k-й по величине элемент в
отсортированном по убыванию порядке — не k-е по величине уникальное значение,
а k-й элемент по позиции, то есть повторы считаются отдельно.

Источник: [LeetCode 215. Kth Largest Element in an Array](https://leetcode.com/problems/kth-largest-element-in-an-array/)

## Разбор

**Полная сортировка.** Самое прямое решение — отсортировать массив по
убыванию и взять элемент с индексом `k - 1`. Сортировка сравнением — O(n log n)
по времени; на дополнительный отсортированный порядок уходит O(n) памяти.

**Куча размера k.** Не обязательно знать точный порядок всех элементов —
достаточно держать k наибольших увиденных значений. Заводим min-куча
размера не больше k: каждое новое число кладём в неё, и если размер
превысил k, выбрасываем минимум кучи (заведомо не входит в k наибольших).
После прохода по всем n числам на вершине кучи остаётся ровно k-е по
величине значение. Каждая вставка и удаление в куче размера k стоит
O(log k), а n чисел дают O(n log k); поскольку k здесь фиксировано (в
задаче и в скейлере k = 10), рост по n линейный — отсюда декларация O(n) с
пояснением в `Note`, что точнее это O(n log k). Память под саму кучу
ограничена k элементами и от n не растёт — O(1) при фиксированном k.
