# Количество островов

Дана прямоугольная сетка из символов `'1'` (суша) и `'0'` (вода). Остров — это
связная группа клеток суши, где соседними считаются только клетки по
горизонтали и вертикали (не по диагонали). Нужно посчитать число островов.

Источник: [LeetCode 200. Number of Islands](https://leetcode.com/problems/number-of-islands/)

## Разбор

Сетку удобно рассматривать как граф, где вершины — клетки суши, а рёбра —
соседство по стороне. Тогда число островов — это число компонент связности
этого графа.

Идём по всем клеткам сетки; встретив непосещённую клетку суши, увеличиваем
счётчик островов и обходом (здесь — в глубину с явным стеком, чтобы не
зависеть от глубины рекурсии на больших сетках) помечаем посещёнными все
клетки суши, до которых можно добраться от неё через соседей. Уже
помеченные клетки при внешнем переборе пропускаются.

Каждая клетка кладётся в стек и снимается с него не более одного раза, так
что суммарная работа по всем обходам — O(n), где n — число клеток сетки.
Память под массив «посещено» и стек в худшем случае (вся сетка — один
остров) тоже O(n).
