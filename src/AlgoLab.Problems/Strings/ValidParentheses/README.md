# Правильная скобочная последовательность

Дана строка, состоящая только из символов `(`, `)`, `[`, `]`, `{`, `}`. Нужно
определить, является ли она правильной скобочной последовательностью: каждая
открывающая скобка должна быть закрыта скобкой того же типа, и порядок
закрытия должен соблюдать вложенность (нельзя закрыть внешнюю скобку раньше
внутренней).

Источник: [LeetCode 20. Valid Parentheses](https://leetcode.com/problems/valid-parentheses/)

## Разбор

Скобки закрываются в порядке, обратном открытию — это классический
принцип «последним пришёл, первым ушёл», то есть стек. Идём по строке слева
направо: встретив открывающую скобку, кладём её в стек; встретив закрывающую —
снимаем верхушку стека и проверяем, что она того же типа. Если стек пуст в
момент закрытия или тип не совпал — последовательность неправильная. В конце
строка правильна тогда и только тогда, когда стек опустел (иначе остались
незакрытые скобки).

Каждый символ обрабатывается один раз с операциями стека за O(1), поэтому
время — O(n). Память — тоже O(n): в худшем случае (все скобки открывающие)
стек вмещает всю строку.
