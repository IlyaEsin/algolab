# Глубина двоичного дерева

Глубина двоичного дерева — это количество узлов на пути от корня до самого
дальнего от него листа; у пустого дерева она равна нулю. Требуется вычислить
это значение для дерева, заданного на вход.

Дерево задаётся массивом обхода в ширину (level-order), где `null` означает
отсутствующий узел на этой позиции — так же, как в исходной задаче на
LeetCode, только явными `int?` вместо строкового представления.

Источник: [LeetCode 104. Maximum Depth of Binary Tree](https://leetcode.com/problems/maximum-depth-of-binary-tree/)

## Разбор

**Обход в глубину.** Глубина дерева — это 1 плюс глубина более глубокого из
двух поддеревьев; для пустого поддерева глубина 0. Рекурсия ровно повторяет
это определение: спуститься в оба поддерева, взять максимум, прибавить
единицу за текущий узел. Каждый узел посещается один раз — O(n) по времени,
а глубина рекурсии равна высоте дерева, что в худшем случае (вырожденное
дерево) даёт O(n) по памяти.

**Обход в ширину.** Тот же результат без рекурсии: раскладываем дерево по
уровням через очередь, на каждом уровне забираем все узлы, которые в неё уже
попали, и кладём их детей — счётчик уровней в конце и есть искомая глубина.
Каждый узел так же посещается один раз (O(n) по времени), а память уходит на
очередь, которая в худшем случае (широкое дерево) хранит целый уровень —
тоже O(n).
