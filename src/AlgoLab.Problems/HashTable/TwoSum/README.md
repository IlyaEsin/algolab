# Сумма двух

Дан массив целых чисел и целевое значение. Нужно найти индексы двух различных
элементов, сумма которых равна целевому значению, и вернуть их по возрастанию.
Гарантируется, что подходящая пара ровно одна.

Источник: [LeetCode 1. Two Sum](https://leetcode.com/problems/two-sum/)

## Разбор

Наивный способ — перебрать все пары, `O(n^2)` по времени и `O(1)` по памяти.

Быстрее — идти по массиву один раз и держать словарь «значение → индекс». Для
текущего элемента `x` нужное дополнение равно `target - x`; если оно уже в
словаре, пара найдена. Один проход, `O(n)` по времени, `O(n)` по памяти.

Ключевая мысль: словарь превращает поиск дополнения из линейного в константный —
типовой размен памяти на время, который дальше встречается постоянно.
